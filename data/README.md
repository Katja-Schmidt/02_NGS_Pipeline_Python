The raw sequencing data are not included in this repository because the FASTQ files exceed GitHub's file size limit.

The paired-end RNA-seq files used in this project are:

- SRR11365252_1.fastq
- SRR11365252_2.fastq

The original dataset can be downloaded from the NCBI Sequence Read Archive (SRA):

https://trace.ncbi.nlm.nih.gov/Traces/?view=run_browser&acc=SRR11365252

or from the European Nucleotide Archive (ENA):

https://www.ebi.ac.uk/ena/browser/view/SRR11365252
